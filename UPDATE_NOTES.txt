What changed:
- Extracted legal name, PAN, GSTIN and CIN can be reviewed and copied into Company Profile / Tax Registration drafts.
- Extracted account-holder name and IFSC can be reviewed and copied into Bank Account drafts.
- Added per-field review signals: format matched, format needs review, or name candidate.
- These signals are heuristic guidance only. They are not OCR character confidence, identity verification, bank verification, or approval.
- Values still require vendor review and manual save.

Apply the update:
1. Extract this ZIP into the existing VendorFlow project root and allow overwrite.
2. Ensure the files land at the exact paths shown above.
3. Backend: from backend folder run `python -m pytest -q` then restart `uvicorn app.main:app --reload`.
4. Frontend: from frontend folder run `npm install` if needed, then `npm run dev`.
5. Upload a synthetic test document containing legal name, PAN, GSTIN/CIN and/or bank account-holder name and IFSC.
